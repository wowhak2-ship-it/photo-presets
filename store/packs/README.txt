Зашифрованные PRO-наборы.

Здесь лежат ТОЛЬКО шифротексты в контейнере PRESETY2 (AES-256-GCM). Они публичные и
без ключа бесполезны — это и есть замысел: файл может скачать кто угодно, а прочитать
только тот, у кого есть лицензия с ключом набора.

Чего здесь НЕ должно быть никогда:
  · открытых мастеров (*.presety.json платных наборов);
  · ключей шифрования;
  · приватного ключа подписи лицензий.

Мастера и ключи живут в отдельном приватном репозитории Presety-PRO-Masters.
